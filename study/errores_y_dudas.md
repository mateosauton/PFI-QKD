# Registro de errores y dudas

Este archivo conserva errores que merecen reaparecer como preguntas futuras. No se
usa para copiar definiciones.

## Formato de una entrada

| Campo | Contenido |
|---|---|
| Fecha | Día en que apareció la dificultad |
| Tema | Concepto concreto, no el nombre de una semana completa |
| Respuesta inicial | Lo que respondí antes de mirar la solución |
| Por qué falló | Supuesto oculto, confusión, cálculo o vocabulario incorrecto |
| Corrección | Explicación reconstruida en mis palabras |
| Fecha de reintento | Cuándo responderé una variante sin apuntes |

## Entradas

Todavía no se registraron errores ni dudas.
