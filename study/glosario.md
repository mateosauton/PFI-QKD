# Glosario mínimo de QKD

| Término | Definición operativa |
|---|---|
| Alice | Nombre convencional del nodo que prepara o inicia los estados y datos del protocolo. |
| APD | *Avalanche photodiode*: detector semiconductor que puede operar para registrar fotones individuales. |
| Base | Conjunto de estados distinguibles usado para preparar o medir un qubit. |
| Bit | Variable clásica con valor 0 o 1. |
| Bob | Nombre convencional del nodo que recibe y mide los estados enviados por Alice. |
| Canal clásico autenticado | Canal público donde cualquiera puede escuchar, pero un atacante no puede suplantar mensajes sin ser detectado. |
| Canal cuántico | Medio físico por el que viajan los estados cuánticos; en la tesis, fibra óptica. |
| Dark count | Click del detector sin un fotón de señal correspondiente. |
| Decoy state | Pulso preparado con una intensidad alternativa para estimar el comportamiento de componentes de distinto número de fotones. |
| Eve | Nombre convencional del adversario que intenta obtener información. |
| Fotón | Cuanto de excitación del campo electromagnético; en óptica se detecta como un evento discreto. |
| Interferómetro | Dispositivo que combina caminos ópticos para convertir diferencias de fase en probabilidades de detección. |
| KMS | *Key Management System*: sistema que almacena, entrega y controla el uso de material de clave. |
| PNS | *Photon-number splitting*: familia de ataques que explota pulsos con más de un fotón. |
| QBER | *Quantum bit error rate*: fracción de bits distintos entre Alice y Bob dentro de una muestra o clave relevante. |
| Qubit | Estado de un sistema cuántico de dos niveles, representable por un vector complejo normalizado de dimensión dos. |
| Reconciliación | Proceso clásico que corrige diferencias entre las cadenas correlacionadas de Alice y Bob. |
| SKR | *Secret key rate*: tasa de bits de clave que permanecen después de contabilizar errores e información potencial de Eve bajo un modelo. |
| SNSPD | *Superconducting nanowire single-photon detector*: detector de fotón único superconductor de alta eficiencia y bajo ruido. |
| Time-bin | Codificación que usa ventanas temporales, por ejemplo llegada temprana y tardía, como modos ópticos. |
| WCS | *Weak coherent source*: fuente láser atenuada con número medio de fotones menor que uno por pulso. |
| Yield | Probabilidad condicional de detección dado que Alice emitió un componente de cierto número de fotones. |
